# MOVEON

카메라로 재활운동 자세를 인식해 횟수와 정확도를 세고, 음성으로 자세를 안내하며, 운동 결과를 AI로 요약해 주는 Android 앱입니다.

## 주요 기능

- **자세 인식 운동 4가지**
  - 무릎 굽힘 운동, 의자 스쿼트, 런지: 반복 횟수와 회차별 정확도
  - 하체 스트레칭: 상체를 숙여 버틴 유지 시간
  - 휴대폰 카메라 영상에서 관절 위치를 찾고, 관절 각도를 운동별 기준 범위와 비교해 판정합니다.
- **음성 안내**: 화면을 보지 않아도 자세 안내, 횟수, 목표 도달을 음성으로 알려 줍니다.
- **AI 리포트**: 운동이 끝나면 정확도와 관절별 오차를 바탕으로 결과를 자연어로 요약하고 다음 운동 팁을 보여 줍니다.
- **기록·통계**: 운동 기록 목록과 상세, 주간 리포트, 목표와 챌린지 진행률을 볼 수 있습니다.
- 운동 전후 컨디션 체크(불편감 0~10, 몸 상태)

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 앱 | Android (Java, XML 레이아웃), minSdk 26 |
| 카메라 | CameraX |
| 자세 인식 | MediaPipe Pose Landmarker (관절 위치 추출만 사용) |
| 자세 판정 | Java에서 관절 각도를 계산해 운동별 기준 범위와 비교 |
| 음성 | Android TextToSpeech |
| 백엔드 / DB | Supabase (인증, PostgreSQL, Row Level Security, Edge Functions) |
| AI 요약 | Gemini (Supabase Edge Function에서 호출) |
| 네트워크 | Retrofit, OkHttp |
| 테스트 | JUnit, MockWebServer |

## 실행 방법

1. Android Studio로 이 저장소를 엽니다.
2. 프로젝트 최상위 폴더의 `local.properties`에 Supabase 접속 정보를 추가합니다.
   이 파일은 `.gitignore`에 들어 있어 Git에 올라가지 않습니다. 실제 값은 저장소에 커밋하지 마세요.

   ```properties
   SUPABASE_URL=https://<프로젝트 ID>.supabase.co
   SUPABASE_PUBLISHABLE_KEY=<Supabase publishable key>
   ```

   - 두 값은 Supabase 대시보드의 Project Settings → API에서 확인할 수 있습니다.
   - 값이 없어도 빌드는 되지만, 로그인과 기록 저장은 동작하지 않습니다.
3. 기기 또는 에뮬레이터를 연결하고 `app`을 실행합니다. 자세 인식은 실제 기기의 전면 카메라에서 확인하는 것을 권장합니다.
4. 단위 테스트: `./gradlew testDebugUnitTest`

## 자세 인식 촬영 방법

- 휴대폰을 **세로로, 똑바로** 세워 둡니다. 하체 스트레칭에서는 휴대폰이 15° 넘게 기울면 "휴대폰을 똑바로 세워 주세요"라고 안내합니다.
- 카메라에 **머리부터 발끝까지** 들어오도록 거리를 조절합니다. 운동 시작 전 카메라 세팅 화면에서 확인할 수 있습니다.
- 카메라를 정면으로 보지 말고 **옆모습**이 보이도록 섭니다. 카메라에 가까운 쪽 다리를 기준으로 판정합니다.

| 운동 | 촬영 자세 |
|---|---|
| 무릎 굽힘 운동 | 의자를 잡고 옆으로 서서, 카메라 쪽 다리의 발뒤꿈치를 엉덩이 쪽으로 들어 올립니다. |
| 의자 스쿼트 | 의자를 몸 뒤에 두고 옆으로 서서, 엉덩이가 의자에 닿을 만큼 앉았다가 일어섭니다. |
| 런지 | 발을 앞뒤로 벌리고 옆으로 서서 위아래로만 움직입니다. 다리를 바꿀 때는 몸을 돌리지 말고 앞뒤 발만 바꿉니다. |
| 하체 스트레칭 | 의자 끝에 옆으로 앉아 한쪽 다리를 앞으로 쭉 펴고, 허리를 편 채 상체를 앞으로 숙여 20초 버팁니다. |
